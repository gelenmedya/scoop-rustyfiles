# Scoop bucket for rustyfiles

[rustyfiles](https://github.com/gelenmedya/rustyfiles) is a fast file manager for Windows, written in Rust.

```
scoop bucket add rustyfiles https://github.com/gelenmedya/scoop-rustyfiles
scoop install rustyfiles/rustyfiles
```

`scoop update rustyfiles` brings new versions: this bucket follows the GitHub releases by itself (the portable zip of each release).

Settings live in `%APPDATA%\rustyfiles`, so they stay through updates.

Problems with rustyfiles itself go to its [issues](https://github.com/gelenmedya/rustyfiles/issues).
